## 方法（硬性规则执行情况）

- 归一化：所有长度同时报原始 px（注明量测图宽度）与占屏宽百分比；禁止跨分辨率直接比原始 px。
  原图字号 CSS 换算统一假设：原图手机 CSS 宽 390px（iPhone 标准宽），即 600 宽裁切缩放 1.538、
  660 宽裁切缩放 1.692；换算式：估计字号 = cap 高 / 缩放 / 0.72（0.72 为无衬线大写字母 cap 高占字号比，
  属假设）。360-412 宽范围内的结论区间在相关行注明；假设敏感项单独列入待量。
- 字体：PIL 量大写字母干列高度（注明坐标与图宽），同时报 cap 高与换算估计字号；
  粗细报观察档（常规/中/半粗/粗）+ 代码 font-weight，不从像素猜精确数值。
- 颜色：5x5 patch 均值（注明坐标，避开边缘抗锯齿）；小圆点用连通域/饱和度聚类定位后取均值；
  白色圆点因饱和度滤波不可见，改用目视计数（方法栏注明）。
- 严重度：critical = 元素缺失/错位/一眼可见错误或尺寸偏差 >25%；major = 偏差 10-25% 或颜色/纹理错误；
  minor = 偏差 <10%。小装饰圆点缺失按 major 计（非结构件，低于 critical 的结构缺失级）；
  结构件缺失（composer、导航头、整列数据）按 critical 计。
- 题号标注：上一轮 22 项选择题中本套相关者为 Q9（重切裁切）/Q10（composer）/Q11（导航 chrome）/
  Q12（J1 圆点 token）/Q13（picker 符号）/Q14（信任规则，仅备注）/Q15（修复优先级，仅备注）。
